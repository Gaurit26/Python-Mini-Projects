# Text-Based Adventure Game

A simple text-based adventure game built using Python. Players make choices at different stages of the game, explore different paths, and experience different endings.

## Features
- Interactive gameplay.
- Takes the player's name as input.
- Multiple story paths and choices.
- Different outcomes based on player decisions.
- Win or lose scenarios.

## Concepts Used
- Python `input()` and `print()`
- Variables
- `if-elif-else` statements
- Nested conditional statements
- String methods (`lower()`)

## How to Run

1. Clone this repository.
2. Open the project in VS Code or any Python IDE.
3. Run the Python file:

```bash
python adventure.py
```

4. Enter your name and start your adventure!

## Game Choices
- Choose left or right at the dirt road.
- Decide whether to walk or swim across the river.
- Choose whether to cross the bridge or go back.
- Decide whether to talk to the stranger.

## Purpose

Created as a beginner Python mini-project to practise conditional statements, user input, and decision-making logic.
