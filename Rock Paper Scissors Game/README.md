# Rock Paper Scissors 🗿📃✂️

A simple Python game where the user plays Rock Paper Scissors against the computer.

## Features

* Allows the user to choose Rock, Paper, or Scissors
* Computer makes a random choice
* Displays choices using emojis
* Determines the winner
* Handles invalid choices
* Allows the user to play multiple rounds

## Concepts Used

* Variables
* User input
* While loop
* If-elif-else conditions
* Random module
* Tuples
* Dictionaries
* `random.choice()`
* f-strings
* `continue` and `break`
* Logical operators (`and`, `or`)

## How to Run

1. Make sure Python is installed on your system.
2. Run the program using:

```bash
python rock_paper_scissors.py
```

3. Enter:

   * `r` for Rock
   * `p` for Paper
   * `s` for Scissors
4. Choose `y` to continue or `n` to exit.

## Example Output
