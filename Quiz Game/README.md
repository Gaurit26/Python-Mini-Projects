# Computer Quiz Game

A simple Python-based computer quiz game where users answer basic computer-related questions and receive a score based on their correct answers.

## Features
- Interactive quiz using user input.
- Four computer-related questions.
- Checks answers using conditional statements.
- Tracks the user's score.
- Calculates the final percentage.

## Concepts Used
- Python `input()`
- `if-else` statements
- String methods (`lower()`)
- Variables
- Type conversion (`str()`)
- Basic arithmetic operations

## How to Run

1. Clone this repository.
2. Open the project in VS Code or any Python IDE.
3. Run the Python file:

```bash
python quiz.py
```

4. Enter your answers and see your final score!

## Sample Questions
- What does CPU stand for?
- What does GPU stand for?
- What does RAM stand for?
- What does PSU stand for?

## Purpose

Created as a beginner Python mini-project to practise basic programming concepts and conditional logic.
