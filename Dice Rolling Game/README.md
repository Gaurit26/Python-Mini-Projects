# Dice Roller 🎲

A simple Python program that simulates rolling two dice. The program generates random numbers between 1 and 6 and displays the result.

## Features

- Rolls two dice randomly
- Generates numbers from 1 to 6
- Allows the user to roll again multiple times
- Simple command-line interaction

## Concepts Used

- Python `while` loop
- `if-elif-else` conditions
- User input using `input()`
- Random number generation using the `random` module
- Variables and formatted strings (f-strings)

## How to Run

1. Make sure Python is installed on your system.
2. Run the program using:

python dice_roller.py

3. Enter:
   - `Y` to roll the dice
   - `N` to exit

## Example Output

Roll the dice? (Y/N): y
(3,6)

Roll the dice? (Y/N): y
